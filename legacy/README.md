# Standalone V28 reference

`board_game_tracker_v28.html` is the previous complete offline HTML release, retained for save exports and comparison. Its embedded assets belong to that archived format. The active React PWA uses external files under `public/` and does not load this HTML.

The V28 build is available with `npm run build:legacy`; active PWA development uses `npm run dev` / `npm run build` instead.
